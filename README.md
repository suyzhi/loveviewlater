# 稍后再看 - 浏览器扩展

在浏览器右侧侧边栏管理稍后再看网页列表，支持右键菜单快速添加，以及浏览进度追踪。

## 功能

- **添加当前页面**：点击侧边栏内「+ 当前页」按钮，或右键页面空白处选择「添加到稍后再看」
- **添加链接**：右键任意链接 → 「链接添加到稍后再看」
- **查看列表**：点击工具栏图标打开/关闭右侧边栏，按添加时间倒序排列；点击页面任意处会关闭侧边栏
- **搜索、筛选、排序**：按标题、网址或来源搜索，并可筛选未读/已读/读到一半/已完成；筛选与排序会被记住
- **命运三选一**：从未读、未完成的历史积压中加权抽取三篇，越早收藏越容易出现；抽中后 7 天内不重复
- **打开页面**：点击列表项跳转到该页面（标题是真的链接，中键/Ctrl+点击可新开标签页）
- **浏览进度追踪**：从侧边栏打开的页面会自动记录滚动百分比，列表项底部显示进度条，并在下次打开时恢复上次滚动位置
- **来源显示**：每条记录显示从哪个网站添加而来，点击来源可打开原来源页面
- **添加反馈**：添加成功后，网页内会播放纸片飞向浏览器工具栏方向的动画；重复添加会置顶原条目并显示对应文案
- **标记已读**：点击复选框给标题添加删除线（左→右滑动动画），再次点击反向滑走
- **永久删除**：点击垃圾桶后变为「删除 / 取消」确认态，确认后才彻底删除；底部「清空全部」两次点击确认
- **平滑列表动画**：添加、删除、筛选排序和删除确认导致条目移动时，列表平滑过渡；条目 DOM 按 id 复用，滚动进度或已读状态更新不会重建整张列表
- **大列表分批渲染**：一次最多渲染 200 行，其余用「显示更多」追加，避免上千条时一次性建满 DOM
- **自动去重**：同一 URL 不会重复添加
- **固定底部工具栏**：导出、导入、刷新、清空等按钮始终停留在侧边栏底部
- **手动导出/导入**：导出版本化 JSON 备份，导入时自动校验、去重并报告无效项
- **隐私友好图标**：优先使用页面已有 favicon，缺失时使用本地字母占位，不请求第三方 favicon 服务
- **透明高清图标**：使用网页卡片、书签和时钟组成的透明底扩展图标
- **深色模式**：自动跟随系统主题
- **持久存储**：使用 `chrome.storage.local`，关闭浏览器不丢失
- **一键重载**：修改代码后点击 🔄 按钮即可重新加载扩展，无需前往扩展管理页面

## 安装

1. 打开 Edge/Chrome 浏览器，地址栏输入 `edge://extensions` 或 `chrome://extensions`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择本项目文件夹

## 技术栈

- Manifest V3（`minimum_chrome_version` 114，Side Panel API 的下限）
- Side Panel API / Context Menus API / Storage API / Scripting API
- 零运行时依赖；开发依赖只有 ESLint

## 性能约定

这几条是「列表长了也不卡」的关键，改动前请先看：

- **存储在内存里**：`background.js` 用 `createListStore` 持有权威列表，只有结构变化（增删、标记、导入）才立刻落盘；
  滚动进度这类高频更新按 1 秒窗口合并写盘，离开页面时带 `flush: true` 强制落盘。
  每次上报都「读全表 + 规范化 + 写全表」在 1000 条时要 5ms 以上并反复重写 380KB，别再退回去。
- **形态版本号**：写盘时每条记录带 `v`（`SCHEMA_VERSION`），读回时命中就跳过 6 次 `new URL()`；
  实测 1000 条从 13ms 降到 1.1ms。字段语义变了就 +1 版本号，旧记录会自然走一次完整迁移。
- **右键菜单不走全页扫描**：用 `document.elementsFromPoint` 做命中测试，取标签文本前先看元素粒度
  （右键点在空白处时 `target` 可能是 `<body>`，直接 `textContent` 会把整页文本复制一遍）。
- **点击监听按需开启**：页面里的 `pointerdown` 只有在侧边栏打开时才上报，否则每次点击都会唤醒 Service Worker。
- **动画脚本按需注入**：`content-add-animation.js` 不在 manifest 里常驻，而是在需要播放时用
  `chrome.scripting.executeScript` 注入，省掉所有站点的解析成本。
- **视图计算是纯函数**：筛选/搜索/排序/分页都在 `core.mjs` 的 `selectVisibleItems` 里，面板一次渲染只算一次。
- **只移动错位的行**：列表重排用「游标 + insertBefore」而不是全量 `append`，避免整表样式重算和打断动画。

## 动画设计

都是为了「不抖」而选的实现方式，改动前请先看这段：

- **网页内添加动画**：外层元素只跑 `transform` 路径，圆角单独挂在纸片上，路径帧里不做模糊/阴影动画，避免逐帧重绘。
- **侧边栏列表**：条目 DOM 按 id 复用；所有 DOM 变更收进同一个 `requestAnimationFrame` 队列；位移用 FLIP，只改 `translateY`，同一行的新动画会先取消旧动画。
- **删除线**：静态样式由 `.strikethrough` 提供，滑动由 WAAPI 负责，两侧不会抢同一个 `background-size`。
- **滚动进度**：侧边栏只在条目顺序真的变化时才重排，页面侧按 400ms 节流上报，后台按 1 秒窗口合并落盘。
- **恢复滚动**：打开页面后最多纠正 5 次、每次只在偏差大于 4px 时才动；用户一旦滚动/按键就立刻停手。
- **减少动态效果**：跟随 `prefers-reduced-motion`，跳过平移动画但保留状态更新。

## 无障碍

- 标题是真正的 `<a href>`：可 Tab 聚焦、回车打开，支持中键/Ctrl+点击新开标签页。
- 命运三选一打开时，背后的控件会设成 `inert` 并加焦点陷阱，Tab 不会跑到列表里。
- 删除、清空、重载都用两步确认，不再用阻塞式 `alert/confirm`。

## 目录结构

```
background.js            Service Worker：消息路由、右键菜单、追踪标签页、内存列表
core.mjs                 纯逻辑：URL 规范化、存储形态迁移、列表存储、视图选择（全部有单测）
constants.mjs            跨文件共享的时间/尺寸常量
content-context.js       常驻内容脚本：右键取 URL/标题、页面点击上报开关
content-scroll-tracker.js 按需注入：滚动进度上报与位置恢复
content-add-animation.js 按需注入：添加成功的纸片动画
sidepanel/               侧边栏页面（panel.html / panel.css / panel.js）
tests/                   node:test 单测（core / store / background / 动画不变量）
```

## 开发

```bash
npm install      # 只装 ESLint
npm test         # 跑全部单测
npm run lint     # 静态检查
npm run check    # lint + test
```

测试不依赖浏览器：`background.js` 用一份 `chrome` 桩直接跑消息路由（含存储写入次数断言），
内容脚本与面板用 `vm` + 假 DOM 跑，或者断言关键不变量（如「路径动画只允许 transform/opacity」）。

修改后的加载方式：`chrome://extensions` → 刷新扩展，或在侧边栏点 🔄。
